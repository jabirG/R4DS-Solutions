## 📖 Project Overview

This repository contains my coding solutions for **16 chapters** of the renowned book, ["R for Data Science"](https://r4ds.had.co.nz/) by Hadley Wickham & Garrett Grolemund. These solutions were developed during my internship with [Posit](https://posit.co/), where I had the opportunity to work under the mentorship of **Mine Çetinkaya-Rundel** and **Tracy Teal**. 

---

## 🔍 About the Solutions

The goal of these solutions is to help learners deepen their understanding of data science by providing clear, well-documented R code for each chapter's exercises. They cover topics ranging from **data wrangling** to **data visualization**, helping users develop a strong foundation in R and the `tidyverse`.

Each solution set in this repository aims to:
- Reinforce key concepts introduced in the corresponding chapter.
- Demonstrate best practices for coding and data analysis.
- Provide comprehensive explanations for complex topics.

## 📦 Tools and Libraries

The solutions rely heavily on the following packages from the **tidyverse**:
- **ggplot2:** For data visualization
- **dplyr:** For data manipulation
- **tidyr:** For reshaping data
- **readr:** For importing data
- **purrr:** For functional programming
- **stringr:** For string manipulation
- **lubridate:** For working with date-time data

These packages were chosen because they streamline the process of performing common data science tasks and align well with the book's content.

```r
# Example code for loading key packages
```
